# 弹框支持 L 站投票

## Goal

用户在话题列表页用增强阅读弹框阅读带 Discourse 投票的帖子时，可以直接查看投票、完成投票、更新或撤销自己的投票，无需跳转到原帖页面。

## Requirements

- 支持弹框内任意楼层的投票，不局限于楼主帖。
- 支持最常见的 Discourse 投票类型：
  - `regular`：单选。
  - `multiple`：多选。
- 支持展示投票选项、可见结果、提交、更新和撤销投票。
- 使用官方接口和当前浏览器登录态，不新增鉴权方式。
- 结果可见性对齐原生 Discourse 语义：
  - `results=always`：打开弹框即显示结果。
  - `results=on_vote`：未投票时只显示选项；已投票或投票成功后显示结果。
  - `results=on_close`：投票未关闭时只显示选项；关闭后显示结果。
  - 其他由服务端决定不可见的结果模式保持隐藏。
  - 已关闭投票禁止继续投票，但按结果可见性规则展示结果。
  - 当前用户已投票且结果暂不可见时，显示“已选择”状态，不显示票数或总人数。
- 投票提交交互对齐原生 Discourse：
  - `regular` 点击未选中的选项后立即提交；点击当前已选项时按原生行为撤销投票。
  - `multiple` 先本地勾选/取消选项，再点击“投票”或“更新投票”统一提交。
  - `multiple` 的 `min/max` 约束控制提交按钮可用性；无有效 `min` 时按 1 处理，无有效 `max` 时按选项总数处理。
- 投票失败或请求进行中使用投票区块内行内状态反馈：
  - 请求期间禁用相关按钮，防止重复提交。
  - 失败时显示“投票失败：xxx”的行内错误提示。
  - 失败后保留用户未提交的选择，便于重试。
- 结果可视化使用基础条形结果：
  - 每个选项显示 HTML 文本、票数、百分比和进度条。
  - 当前用户已选项高亮。
  - 不做饼图、投票者列表或分组统计。
- 已投票后的更新与撤销入口：
  - 结果可见时，直接切换选项或修改多选后提交即可更新。
  - 结果不可见时，保留可点击的已选项，用户调整后仍可提交更新。
  - 仅在允许修改且当前用户已投票时显示“撤销投票”按钮。
  - 点击撤销按钮直接调用撤销接口，不做确认弹窗。

## Out of Scope

- `number` 数字评分投票。
- `ranked_choice` 排名投票。
- 投票者列表、分 voters。
- 关闭/打开投票。
- 导出投票结果。
- 匿名未登录投票队列或登录引导流程。

## Acceptance Criteria

- [ ] 打开带 `regular` 投票的帖子时，弹框能渲染投票选项和当前状态。
- [ ] 打开带 `multiple` 投票的帖子时，弹框能按 `min/max` 限制选择与提交。
- [ ] 用户在弹框内提交单选或多选投票后，选项、票数、总人数和当前用户选择同步更新。
- [ ] 用户更新或撤销投票后，结果状态同步更新且不产生重复渲染。
- [ ] 投票接口失败时保留用户可理解的操作反馈，并避免界面进入假成功状态。
- [ ] 无投票、不支持类型、已关闭投票、结果不可见等边界状态不会破坏原有帖子渲染。
- [ ] 原有点赞、回复、收藏、Boost、分片加载和已读上报功能不回归。

## Background

- 本仓库是单文件用户脚本：`LinuxDo 增强阅读.user.js`。
- `renderPost()` 直接将 Discourse 返回的 `post.cooked` 渲染到自建弹框 DOM 中；投票静态结构会进入 DOM，但当前没有 poll 数据渲染和交互绑定。
- Discourse post JSON 在含投票时返回 `post.polls`；登录用户已投票时返回 `post.polls_votes`，其结构为 `poll_name -> option digest 数组`。
- Poll 对象包含 `name`、`type`、`status`、`results`、`min`、`max`、`options`、`voters` 等字段。选项包含 `id`、`html`，且只有服务端允许当前用户查看结果时才包含数字型 `votes`。
- Discourse poll 官方接口：
  - 投票/更新：`PUT /polls/vote`，参数 `post_id`、`poll_name`、`options`，返回 `{ poll, vote }`。
  - 撤销：`DELETE /polls/vote`，参数 `post_id`、`poll_name`，返回 `{ poll }`。
- 仓库现有 `apiSend()` 已使用同源 `fetch`、登录 Cookie、CSRF Token 和表单编码，可复用；但它当前会把数组参数序列化成逗号字符串，需要为投票选项数组补充表单数组编码。
